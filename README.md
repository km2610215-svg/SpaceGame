# GRAVITY: Juderella Rescue
A browser-based 3D space gravity game for GitHub Pages.

## Deploy
Repository Settings → Pages → Deploy from a branch → main → /(root).

URL: https://km2610215-svg.github.io/SpaceGame/

## Controls
- WASD / arrow keys: thrust and steer
- Throttle slider: adjust propulsion
- X/Y/Z sliders: attitude control
- 0.25×, 0.5×, 1×, 2×: simulation time
- PC right-click planet / mobile long press: inspect

## Includes
- 10 space navigation levels + bonus Level 11
- Procedural planets, stars, black hole, wormhole, asteroid belt, UFO
- Approximate trajectory visualization
- Browser-local persistent leaderboard
- CSV, JSON, TXT leaderboard exports

Scores are stored per browser in localStorage. Shared cross-device ranking requires a backend.
